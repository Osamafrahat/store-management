## 🔴 Phase 1: Security Fixes (Week 1-2)

### 1.1 Remove Hardcoded Secrets
| File | Issue | Fix |
|------|-------|-----|
| `server/src/db/supabase.js:3-4` | Hardcoded Supabase URL & anon key | Remove defaults, require `SUPABASE_URL`, `SUPABASE_ANON_KEY` in `.env` |
| `server/src/middleware/auth.js:3` | Hardcoded JWT secret | Require `JWT_SECRET` in `.env`, generate strong 64-char secret |
| `server/package.json` | No `.env.example` | Create `server/.env.example` with all required vars |

### 1.2 Fix Row Level Security Policies
**File:** `server/supabase-schema.sql` (lines 200-218)
- **Current:** `USING (true)` - allows any authenticated user full access
- **Fix:** Restrict to service role only, add user-based policies for customer-facing data

```sql
-- Example fix for customers table
DROP POLICY IF EXISTS "Allow all for service role" ON customers;
CREATE POLICY "Service role full access" ON customers FOR ALL USING (auth.role() = 'service_role');
CREATE POLICY "Users read own store customers" ON customers FOR SELECT USING (true); -- Add store_id when multi-store
```

### 1.3 Strengthen Authentication
| File | Fix |
|------|-----|
| `server/src/routes/auth.js` | Add password complexity validation (min 8 chars, uppercase, number, symbol) |
| `server/src/routes/auth.js:90` | Increase bcrypt cost from 10 to 12 |
| `server/src/middleware/auth.js` | Add refresh token rotation, reduce access token to 15min |

### 1.4 Harden Express Security
**File:** `server/src/index.js`
- Enable Helmet CSP: `contentSecurityPolicy: { directives: { defaultSrc: ["'self'"], ... } }`
- Add `hsts: { maxAge: 31536000, includeSubDomains: true }` for production
- Reduce rate limits: `max: 100` for general, `max: 10` for auth

1. Install: `npm i @tanstack/react-query @tanstack/react-query-devtools`
2. Create `client/src/lib/queryClient.ts`
3. Wrap `App` with `QueryClientProvider`
4. Replace each store's `fetchData` with `useQuery`:
```typescript
// Before (POSPage.jsx)

useEffect(() => { productsApi.getAll().then(r => setProducts(r.data)) }, []);

// After
const { data: products } = useQuery({ queryKey: ['products'], queryFn: productsApi.getAll });
```

## 🟡 Phase 3: Feature Roadmap (Week 4-8)

### 3.1 Purchase Orders (Suppliers Workflow)
**New Tables:**
```sql
CREATE TABLE purchase_orders (
  id BIGSERIAL PRIMARY KEY,
  po_number TEXT UNIQUE NOT NULL,
  supplier_id BIGINT REFERENCES suppliers(id),
  status TEXT DEFAULT 'DRAFT', -- DRAFT, SENT, RECEIVED, CANCELLED
  expected_date DATE,
  total_amount NUMERIC DEFAULT 0,
  created_by BIGINT REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE purchase_order_items (
  id BIGSERIAL PRIMARY KEY,
  po_id BIGINT REFERENCES purchase_orders(id) ON DELETE CASCADE,
  product_id BIGINT REFERENCES products(id),
  quantity INTEGER NOT NULL,
  unit_cost NUMERIC NOT NULL,
  received_quantity INTEGER DEFAULT 0
);
```

**API:** `POST /api/purchase-orders`, `POST /api/purchase-orders/:id/receive`

### 3.2 Audit Logging
**New Table:**
```sql
CREATE TABLE audit_logs (
  id BIGSERIAL PRIMARY KEY,
  user_id BIGINT REFERENCES users(id),
  action TEXT NOT NULL, -- CREATE, UPDATE, DELETE, LOGIN, etc.
  entity_type TEXT NOT NULL, -- products, orders, users
  entity_id BIGINT,
  old_data JSONB,
  new_data JSONB,
  ip_address INET,
  user_agent TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_audit_logs_entity ON audit_logs(entity_type, entity_id);
CREATE INDEX idx_audit_logs_user ON audit_logs(user_id, created_at);
```

**Middleware:** `server/src/middleware/auditLogger.ts` - auto-logs all mutating requests

**Example Test:**
```typescript
// server/tests/integration/routes/products.test.ts
import { describe, it, expect, beforeAll, afterAll } from 'vitest';
import request from 'supertest';
import app from '../../src/index.js';

describe('Products API', () => {
  let authToken: string;
  
  beforeAll(async () => {
    const login = await request(app).post('/api/auth/login').send({ username: 'admin', password: 'admin123' });
    authToken = login.body.token;
  });

  it('GET /api/products - returns paginated products', async () => {
    const res = await request(app)
      .get('/api/products?page=1&limit=10')
      .set('Authorization', `Bearer ${authToken}`);
    expect(res.status).toBe(200);
    expect(res.body.data).toBeInstanceOf(Array);
    expect(res.body.pagination).toBeDefined();
  });
});
```
